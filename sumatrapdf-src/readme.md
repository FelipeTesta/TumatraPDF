## TumatraPDF Reader (Fork with Flashcard MVP ✅, Arch Tools ✅, Page Filter ✅, Structured Logging ✅)

SumatraPDF is a multi-format (PDF, EPUB, MOBI, CBZ, CBR, FB2, CHM, XPS, DjVu) reader
for Windows under (A)GPLv3 license, with some code under BSD license (see
AUTHORS).

### Roadmap / Features
- [x] Flashcard MVP — core toggle, study mode, SM-2, card creation, sidebar, filter, logging
- [x] Arch Tools — Clean All, per-page scale, button highlights, Ctrl+Arrow page nav
